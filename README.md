## О проекте

Этот проект сделан **исключительно на основе собственных знаний** — без туториалов, без копипасты, только то, что уже изучено и понято. Главная цель — практика и закрепление Vanilla JavaScript. Код будет постепенно улучшаться по мере роста навыков.

---

## Что умеет сайт

- 🎥 **Hero-секция** — случайный популярный фильм при каждой загрузке
- 🕐 **Недавно обновлено** — последние добавленные фильмы (2024–2026)
- 🔥 **В тренде** — топ фильмов с высоким рейтингом KP/IMDB/TMDB
- 🆕 **Новые релизы** — свежие кинопремьеры
- ⭐ **Рекомендации** — с фильтрацией по категориям (фильмы / сериалы / аниме)
- 🔍 **Поиск** — модальное окно с детальной информацией о найденном фильме

---

## Стек

| Технология | Применение |
|---|---|
| HTML5 | Семантическая разметка |
| CSS3 | Flexbox, анимации, CSS-переменные, адаптив |
| Vanilla JavaScript ES6+ | Модули, классы, async/await |
| Fetch API | Асинхронные запросы к API |
| Kinopoisk API | База данных фильмов |

- ✅ ES6+ модули (`import` / `export`)

- ✅ DOM-манипуляции и динамический рендеринг HTML
- ✅ Event Listeners и делегирование событий
- ✅ CSS Flexbox и адаптивная вёрстка
- ✅ CSS-переменные, анимации и переходы

## Запуск

```bash
git clone https://github.com/medok-ui/Movie-Website.git
cd movie-website
```

Открой `index.html` в браузере или запусти через Live Server в VS Code.

> Требуется подключение к интернету для запросов к API.
